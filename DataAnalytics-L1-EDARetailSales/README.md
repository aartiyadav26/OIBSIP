Data Analytics – Level 1: EDA on Retail Sales Data

Project Overview

This project is part of the Oasis Infobyte Data Analyst Internship (OIBSIP). The objective is to perform Exploratory Data Analysis (EDA) on retail sales data and identify useful patterns and trends.

Objectives

- Explore and understand the retail sales dataset.
- Check missing values and duplicate records.
- Analyze sales trends over time.
- Study sales by product category, product, gender, age group, and payment method.
- Visualize findings using charts and graphs.

Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

Analysis Performed

- Data inspection and cleaning
- Sales calculation using quantity and price
- Monthly and quarterly sales analysis
- Age group and gender analysis
- Top-selling products analysis
- Product category sales comparison
- Correlation heatmap
- Payment method sales analysis

Project File

"Aarti_Task1.ipynb" – Contains the Python code, analysis, and visualizations.

Conclusion

This project demonstrates basic exploratory data analysis techniques and the use of Python visualizations to understand retail sales data.
