# EDA on Retail Sales Data

This project performs Exploratory Data Analysis on retail sales data to uncover patterns, trends, and actionable business insights.

## Objective
To analyze retail sales data and identify category performance, seasonal trends, top-selling products, and regional sales distribution.

## Tools Used
- Python
- Pandas
- Matplotlib

## Key Insights
- Technology products generated the highest total sales
- Sales show seasonal fluctuations with an upward trend (2015-2018)
- West region contributes the largest share of sales (31.4%)
